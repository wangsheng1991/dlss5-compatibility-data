# Corrections and additions

This dataset only stays useful if every row can be traced to something NVIDIA actually published.

## To correct a status

Open an issue with:

1. The GPU (name as it appears on NVIDIA's page).
2. The exact NVIDIA URL you read.
3. The date you read it.
4. What the page says, quoted.

An issue without a citable official source will be closed with `unknown` left in place. That is not a rejection of your report — it is the rule that keeps the table trustworthy.

## What will not be merged

- A status justified by a YouTube video, a forum post, a benchmark site or another compatibility table (including a competitor's).
- "Everyone knows the 40 series is supported" without an NVIDIA page that says so for that family.
- Filling `unknown` with a guess because a blank cell looks bad.
- Claims about in-game performance. This dataset answers "does the hardware have it", not "how fast does it run".

## Adding a GPU

Say which NVIDIA (or AMD/Intel) page names it, the checked date, and whether it is `confirmed`, `planned`, `unsupported` or — the usual honest answer for older cards — `unknown`.

## Scope

NVIDIA RTX 50 / 40 / 30 / 20, GTX 10, Radeon and Arc. We are deliberately slow: every row costs a human opening a page.
